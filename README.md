## 🚀 8 Core Platform Modules
1. **Construction Material Marketplace** — Direct procurement of Cement, TMT Steel, M-Sand, Bricks, Electrical, and Plumbing with daily city-wise rates and bulk discounts.
2. **Reverse Auction Engine** — Upload project BOQ, launch 2-hour competitive bidding, and achieve lowest landed factory prices.
3. **On-Demand Home & Civil Services** — GPS-based booking of verified electricians, master plumbers, painters, carpenters, waterproofing experts, and civil contractors.
4. **Labour Net** — Skilled tradesmen network (masons, bar benders, helpers, shuttering carpenters) with admin-benchmarked daily wages.
5. **Real Estate Hub & DIY Land Survey** — Valuation intelligence comparing Sub-Registrar guidance values, registered transaction averages, 1-year growth forecasts, and satellite GPS boundary demarcation.
6. **2D/3D Drawing Studio & Floor Plans** — 100% Vastu-compliant architectural floor plans with CAD dimensions, photorealistic 3D renders, and turnkey budgets.
7. **19 Engineering Calculators & Dynamic BOQ** — Comprehensive civil suite (Concrete, Steel, Tiles, Paint, Blockwork, Brickwork, Plastering, Structural load, Plumbing, Electrical, Excavation, Roofing, Water Tank, Solar, etc.) with real-time exportable PDF & Excel BOQ.
8. **Home Loan & Affiliate Partner Portal** — Construction loan EMI optimizer with stage-wise disbursement planning and partner referral tracking.

- **Framework:** React 18 with TypeScript

- **Styling:** Tailwind CSS with custom brand palette & smooth scroll keyframes
- **Icons:** Lucide React
- **Routing:** React Router v6

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/shaikmuzammil2905/build-mitra.git

# Enter project directory
cd build-mitra

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
